# 青河市 · 像素沙盒世界

浏览器中的俯视像素城市，使用 React、Vinext 和 Canvas 2D。界面控件沿用项目自带的 Shadcn / Base UI，图标来自 Lucide。地图为程序绘制，无外部图片依赖。

## 运行

```sh
npm install
npm run dev
```

生产构建：`npm run build`。类型检查：`npx tsc --noEmit`。城市完整性检查：`node scripts/check-world.mjs`。

## 已有内容

- 2400 × 1700 世界，47 栋建筑，住宅社区、商店、市政厅、图书馆、河畔钟楼。
- 青禾小学、明德初中、青河一中、青河大学与理工学院；校园有运动场、跑道、庭院。
- 连续河流、4 座桥、20 个互通路网节点；144 名行人和 36 辆车沿道路与人行道移动。
- 昼夜循环、窗灯与路灯，暂停与 1× / 2× / 5× 模拟速度。
- 拖动、缩放、可点击缩略地图、建筑详情、学校定位、名称与网格图层。
- 在空地种树、建住宅、移除自己创建的物件。建造会校验河流、道路、建筑、树木和公共校园占地。

## 操作

拖动平移，滚轮缩放；触屏单指拖动并用缩放按钮缩放。WASD / 方向键平移，空格暂停，1–4 切换探索 / 种树 / 住宅 / 移除，0 回到全景。点击建筑查看详情。

世界内容与改动仅在当前页面会话中保留，刷新恢复种子 2417 的城市。常住人口为住宅人数之和；学校显示规划容量，不与人口重复相加。居民是沿道路移动的场景角色，不包含上学、职业或经济决策模型。

## 代码

- `lib/world/model.ts`：地图数据、路网、移动模拟和建造规则。
- `lib/world/render.ts`：地形、房屋、树木、校园、桥梁和角色像素绘制。
- `app/page.tsx`：镜头、交互、时间、详情面板及缩略地图。
- `app/globals.css`：界面样式和响应式布局。

## 验证记录
