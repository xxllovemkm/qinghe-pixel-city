# 学习 APP 界面资源

手机外框、消息布局与 Markdown 数学渲染来自 StudyMode 的 `study_scene_demo`。`markdown.js` 提取该页面共用渲染器；运行中的学生会话由 SchoolDay API 提供。第三方版本、来源、许可与 SHA-256 见 `vendor/manifest.json`。

`manifest.json` 记录来源 `app.js`、提取代码区段和当前交付 `markdown.js` 的 SHA-256，并关联第三方清单。`vendor/manifest.json` 中的 `files` 哈希同时对应来源和交付的 67 个第三方文件。正文中的连续填空横线由行内规则保留，代码与公式沿各自的语法处理。
