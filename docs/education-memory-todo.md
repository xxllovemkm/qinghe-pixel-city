# 青河市教育 Memory 与校园模拟任务待办

整理日期：2026-09-13

目标：让中国教材目录与教学设计决定每节课的教学内容。教师组织课堂与随堂练习、布置完整作业；学生从学校回到青河市的住所，完成整份作业并交给个人学习 APP 批改、讲解和辅导。APP 从本人实际提交与后续交互形成教育 Memory，原教学设计的目标节点作为索引和学习路径。人物设定、真实画像与 APP 预测画像分别可查看，两个个人 3D 图中的每个已学节点都显示掌握度。

本文是实施与验收清单。复选框表示该条实现及所列验证已经完成；未勾选条目包含尚待落实或验收的内容。第三节保留实施前的历史基线，当前实现、命令、结果与边界见[教育 Memory 实施与验收](education-memory-implementation.md)。

## 一、任务总览与实施顺序

课程与学校日是运行主线，知识画像与材料能力随真实学习过程接入。

| 顺序 | 任务 | 交付结果 |
| --- | --- | --- |
| 1 | C1 教材目录与教学计划 | 按年级固定周课表选择课程，保留学期教材绑定、原始身份与来源 |
| 2 | C1／C3 教师授课与完整作业 | 40 分钟活动、例题、随堂练习、12–20 题多题型作业、每生原答和整份提交 |
| 3 | C2 青河市学校日 | 学校、住宅和道路身份；上课、放学、通勤、居家学习的时间与事件 |
| 4 | B2／B3／B4 居家 APP | 逐题批改、错因讲解、连续问答、本人证据与学习记忆 |
| 5 | A1／A2／A3 知识索引与画像 | 原教学目标节点、人物设定、真实与 APP 两种掌握状态及 3D 证据展示 |
| 6 | V1／V2 联合验收 | LiteLLM 实际运行、逐学生统计、独立课程／批改／对话评测及浏览器交互 |

模拟与评测统一调用 LiteLLM API。不同学生、班级和课程可以并发运行，同一学生的活动按因果顺序提交。可配置每次运行 1–200 个请求并发；实际网关吞吐以请求账本和测量结果为准。

每个任务完成时记录：实现位置、运行命令、验证样本、结果文件、剩余问题。新增能力沿当前模块边界接入，保持文档中的唯一任务编号，便于追踪。

## 二、共同设计要求

### 2.1 知识结构、个人状态与显示方式

三者分别保存：

| 层次 | 含义 | 更新来源 |
| --- | --- | --- |
| 完整知识结构 | 原教学目标节点、学科与教材层级、课程顺序及来源版本 | 教学设计目录、原文、资源身份与文件哈希 |
| 个人状态 | 学生对节点的接触经历、真实掌握或 APP 掌握估计、证据和历史 | 相应角色能够获得的经历与信息 |
| 显示方式 | 哪些节点显现、如何区分直接观察和推断、当前展开哪段路径 | 相应角色的个人状态与视图选择 |

同一学科以统一根入口展开，例如“数学”。包含关系组织学段、版本、教材、单元、课时和目标；课程顺序保留来源排列及其核对状态。先修关系需要独立教学审核。目标节点预先存在，个人学习发生时更新状态并使相应目标显现。

真实画像与 APP 画像使用相同的公共节点身份，但各自显现的节点集合、掌握判断、证据量和更新时间可以不同。APP 形成的节点集合也可能包含误判或漏判，应保留这些差异供研究。

### 2.2 三种角色的信息依据

| 角色 | 信息依据 | 用途 |
| --- | --- | --- |
| 模拟器真实画像 | 初始学习历史、课堂参与、作答、辅导经历、学习与遗忘机制、个人状态 | 驱动学生后续行为，作为模拟研究中的参照 |
| 教师观察 | 教师实际看到或听到的课堂活动、学生作答及已获得的材料 | 形成教师自己的课堂判断 |
| APP 推断画像 | 该学生主动分享的材料、本人对话、APP 批改与后续交互；公共知识结构 | 形成学情估计，选择讲法、诊断任务和后续练习 |

课程表是校园模拟的运行依据。学生今天上过哪节课、真实掌握如何，均通过相应经历进入真实画像；APP 的个人判断须能追溯到它实际获得的交互。研究页面可以并排比较各视图，教育 Agent 的提示词按角色投影。

### 2.3 接触、掌握和证据分别记录

- “接触过／学过”描述学习经历，“掌握度”描述能力状态，两者分别变化。
- 学生上过一节课后，可以显现相关节点，但理解、独立应用和保持程度仍有个体差异。
- APP 对本人已分享证据关联到的目标形成掌握预测，首次接触使用声明的数值先验；后续评分证据逐步更新。
- 每个个人图只显示本视角已学过的目标；显示节点必有 0–1 的有限掌握度、来源依据和更新时间。
- 尚无证据为未知；有失败证据、低掌握度和零星状态具有不同含义。
- 当前模拟量规以 60%、80%、95% 为一星、二星、三星起点；页面展示公式、证据权重和量规版本，掌握预测与实际作答统计分别保存。
- 会话结束、学生表示理解、当次答对、独立迁移成功、隔日保持是不同事件。

### 2.4 模拟时长与现实耗时

课堂、讨论、练习、移动和休息使用模拟世界的时间。模拟课表中的一个课时可以占 40 分钟，现实执行由模拟流速、事件处理和模型响应决定。

| 时间 | 记录内容 | 用途 |
| --- | --- | --- |
| 模拟时间 | 日程、每个活动的开始／结束、学习投入、休息与隔日变化 | 排课、学习变化、疲劳、保持与遗忘 |
| 现实执行时间 | 模型请求、解析处理、事件计算、实际运行耗时 | 成本、性能、超时与运行管理 |

模型等待属于现实执行开销。学习时长按事件规定的模拟时长计算。加速运行仍遵守事件因果与个人对话顺序。
