# 青河市 K12 学习模拟评测设计

版本：1.0　日期：2026-09-14　状态：评测设计，待案例集与评分一致性验证。

本评测回答两个问题：模拟学生的表现与变化是否可信；APP 能否理解学生、组织学习证据并持续帮助学生学习。评测分为学生、APP 两大维度，共七个子维度。每个指标均给出测试任务、评分标准，以及同一情境下的理想态高低表现。

[交互式案例展示](../public/qinghe-evaluation-design.html)：通过模拟中的学习手机、Memory 记录与三维画像查看构造病例。支持对话回放、更新前后对比、证据回溯及逐条量化记录。

文中案例、分数、概率和实验结果均为构造的评分示例，用于说明判分边界。它们不是青河实测结果，也不是模型准入阈值。数学案例用于说明机制；正式案例集需要覆盖适用学段、学科和任务类型。

## 1. 评测结构与使用阶段

| 端 | 子维度 | 需要回答的问题 | 指标 |
| --- | --- | --- | --- |
| 学生 | 行为真实性 | 表现能否由知识状态、人物属性和实际交互解释？ | S1、S2、S3、S-E1 |
| 学生 | 学习变化机制 | 变化是否有经历依据，状态与后续能力是否相符？ | S5、S6 |
| APP | 教学交互质量 | 面对学生当下表现，教学行为是否恰当？ | LearnLM 七项 |
| APP | 知识关联与困难诊断 | 找到的知识和错因是否成立，如何验证？ | D1—D3 |
| APP | Memory | 经历如何被保存、整合、修正、检索和用于教学？ | M1—M9、M-E1—M-E3 |
| APP | 学情画像 | 能力判断的范围、证据、时效和置信程度是否合理？ | P1—P11 |
| APP | 持续教学效果 | 学生的独立能力、迁移和保持获得多少增益？ | L1—L4 |

Memory 的对象是学习事件、困难假设、教学方法经验和待完成任务；画像的对象是由这些证据推断的当前能力、适用条件和不确定性。例如，Memory 可以准确记录“提示后答对”，画像仍可能将其高估为“已经独立掌握”。两个环节分别评分。

### 1.1 当前证据与后续校准

| 阶段 | 可开展工作 | 结论范围 |
| --- | --- | --- |
| 当前自然运行 | S1、S3、S-E1、S5；有足够人物样本时开展 S2；对实际对话开展 LearnLM | 行为与经历一致性、模拟内部自洽、可观察教学质量 |
| 专项案例评测 | D、M、P 的证据推理与机制测试；使用审核案例、历史事件回放和冻结输入 | 在给定证据上的正确性；对应评测入口与数据需逐项准备 |
| 独立作答验证 | P8—P11、L1—L3 的结果采集 | 对未来作答的预测表现、学习表现变化；模拟结论受学生模型可信度约束 |
| 学生模型校准后 | S6 外部校准、L4 配对实验及教学收益解释 | 经校准条件下的模拟机制结论；真实学生收益还需要真实学生研究 |

“可开展”表示测试任务有可获得的输入，不表示评测器已经实现。当前先使用正常课程、练习、辅导和后续作答形成的经历判断学生。当前实现中掌握增量受活动时长、类型和人物参数影响；状态数值上涨必须与实际作答证据分别解释。

### 1.2 专项与整链测试

- **专项测试**：为被评模块提供固定且经审核的上游输入。Memory 使用完整事件记录；画像使用正确、带来源的记忆与证据；诊断使用审核题目和分支回答。测试用于定位模块自身能力。
- **整链测试**：沿青河真实运行采集原答、批改、Memory、画像和后续教学。保留上游错误及其传播路径，判断整个系统的实际表现。
- 同一病例可以连接多个指标，但各指标回答自己的问题。M7 的任务接续得分不能代替 L3 的保持成绩，LearnLM 的引导得分不能代替 D2 的错因验证。

## 2. 统一判分协议

### 2.1 三种分数

| 类型 | 判分方式 | 汇总方式 |
| --- | --- | --- |
| 1–5 分 | 四项可观察行为 A—D，各判 true/false；分数 = 1 + true 数量 | 每指标报告样例等权均值、1—5 分分布及各检查点命中率 |
| 0/1 | 对明确错误判定：发生 = 1，未发生 = 0 | 错误发生率；越低越好 |
| 直接量化 | 按冻结标签、预测和实际作答计算 | 保留单位、方向、分母和区间，不换算为任意 1–5 分 |

1–5 分必须先判检查项再计算。全文 5 分示例对应 `[1,1,1,1]`，1 分示例对应 `[0,0,0,0]`；2、3、4 分按实际命中数计算。高分示例中的多轮描述代表完整短案例，不是单句必须同时实现全部能力。

评分者判断是否发生了符合标准的行为：诊断必须与实际证据相符，记忆必须实际保存或更新，教学任务必须实际提出。输出意图、自我评价或术语数量不能单独支持命中。检查点有否定性约束时，需要完整评测窗口才能判断。

直接量化指标用“较好／较差”示例说明方向。误差为 0、错误率为 0 可以是高质量表现。具体数值不作为统一通过线。

### 2.2 案例与证据

每个案例至少冻结以下内容：

| 内容 | 要求 |
| --- | --- |
| 身份 | case_id、指标 ID、量规版本、输入哈希；运行案例补充 run_id、student_id、事件 ID |
| 情境 | 学段、学科、知识目标、任务条件、帮助条件、模拟时间、观察窗口 |
| 被评证据 | 原题、原答、真实消息、记忆前后版本、实际检索、画像前后版本等必要投影 |
| 裁判参照 | 审核标签、可接受解释或行动集合、标准答案及适用条件；只向评测器提供 |
| 结果 | A—D 判定或直接计算输入、证据定位、得分、理由、错误标记和状态 |

LearnLM 的命中引用 APP 连续原文，保持原量规证据规则。新增指标引用对应学生发言、记忆原文、状态字段路径或事件记录，支持前后对比；不能用标准答案冒充被评对象的表现。机械校验负责证据确实存在，语义裁判负责证据是否支持判定。

模拟器隐状态属于研究参照；APP 只获得本人实际可见证据。保留题作答、标准答案和后续事件在预测时不可见。完整原答用于独立评分，APP 自评分只作为待审核数据。

### 2.3 缺失、适用性与可信度

- **scored**：触发条件与证据齐全，能够完成评分。
- **not_applicable**：自然片段没有触发该能力，例如学生从未卡住，无法观察策略切换。
- **awaiting_evidence**：需要的后续独立作答或状态轨迹尚未出现。
- **error**：采集、传输、解析或评分执行失败。

专项案例预先保证四项检查均有触发机会。自然片段不足时按上述状态记录，保持原量规四项结构。未触发与执行失败分别统计，不用高分、低分或零分代替。

单个通过引文不足以抵消同一检查项的直接反证。新增检查项按冻结窗口内的完整证据判定；存在实质违背则记 false。LearnLM 保持源量规原有检查含义。病例中的明确错误同时进入相应 0/1 指标。

模型 Judge 做行为和语义判定，程序做换算、证据定位与数量计算。正式运行前，由两名独立评分者对同一批分层案例判分，报告逐检查点一致率和分歧；经裁决固定边界后再扩大规模。

## 3. 学生端：行为真实性

### S1 知识与行为一致性

**测什么／怎么测**：从正常运行选择状态完整的学生，核对已掌握、薄弱与未学知识对应的多道题、解释和求助行为。以学生—知识范围—连续窗口为案例单位。知识状态若只是数值，需事先明确它对应的能力描述。

**四项检查**：A 已掌握范围有对应解题能力；B 薄弱范围呈现与状态相符的困难；C 解释与答案反映相容的理解程度；D 跨题表现与状态整体一致，偶然猜对和失误有合理空间。

**共同情境**：五年级学生会同分母加法，异分母加法薄弱；窗口中有同分母题、异分母题和理由追问。

- **高分示例｜5 分**：同分母题大多答对并解释“每份大小相同”；异分母题尝试分别相加，追问时承认“不知道怎样合成同一种份”；后续等价题呈现相同卡点，偶然一题猜对时也无法解释通分。A—D 均有多题依据。
- **低分示例｜1 分**：同分母题反复表示完全不会，异分母题却连续给出熟练通分与迁移；错误答案配着与计算无关的完美解释；没有新经历时下一题又变成完全不懂。A—D 均不成立。

### S2 个体差异的行为落实

**测什么／怎么测**：按知识、题目和学习经历匹配学生，考察人物属性是否落实到对应行动。使用配置中可控制的单一属性；无法匹配的自然样本仅报告关联。人物身份属性不能自动作为能力差异依据。

**四项检查**：A 差异体现于相关行动；B 方向符合事先声明的属性定义；C 多个匹配情境中可观察；D 无关能力保持相容。

**共同情境**：知识与任务匹配的两组学生，求助主动性不同，各观察三次卡点。

- **高分示例｜5 分**：主动求助组会较早提出“我卡在找公分母”，另一组先反复尝试，之后才提问；三次卡点都有同方向差异，两组独立计算能力仍与相同初始知识一致。
- **低分示例｜1 分**：两组只有自我介绍说法不同，求助时机与行动随机反转；跨任务看不到稳定模式，求助属性还使一组突然掌握未学内容。四项均未命中。

### S3 交互响应与连续性

**测什么／怎么测**：从已有多轮交互中选择包含具体追问、学生尝试、澄清或讲解的窗口，检查学生是否接续实际输入与已有解法。

**四项检查**：A 回应实际上一轮任务；B 回应内容随新信息发生有依据的变化；C 延续自己的已知步骤与困难；D 理解或立场变化能追溯到具体经历。

**共同情境**：学生已求出公分母 6，APP 问“1/2 需要变成几个 1/6？”，随后学生解释并接受追问。

- **高分示例｜5 分**：学生回答“3 个，因为半个能分成三份六分之一”，随后尝试把 1/3 改写成 2/6；仍不确定相加时分母是否改变，继续针对这一点求助。变化与实际提示和自己的进展对应。
- **低分示例｜1 分**：学生无论问题内容都回复“懂了，谢谢”；随后编造此前已证明的结论，突然声称从未见过分数，再完整给出高阶推导。实际回应、连续性与变化依据均缺失。

### S-E1 无依据能力跃迁

**测什么／怎么测**：对完整连续轨迹做 0/1 判定。先明确能力参照，再检查是否出现没有相应学习或信息依据的持续能力跃迁。单次答对不足以触发；缺少前后轨迹记 awaiting_evidence。

**共同情境**：初始多题证据显示学生尚不理解通分，之后考查独立解释与变式。

- **高质量示例｜0**：经历单位解释、本人尝试与独立验证后，能够通分；或学习前偶然猜对一题但仍不能解释。没有持续无依据跃迁。
- **低质量示例｜1**：没有新增学习经历，后续三道陌生变式均熟练完成，并给出系统推导；其能力与此前稳定困难直接冲突。

汇总为发生该错误的有效轨迹数／有效轨迹总数，越低越好。

## 4. 学生端：学习变化机制

### S5 学习状态变化的证据一致性

**测什么／怎么测**：从正常模拟抽取同一学生的学习前表现、课堂或练习经历、状态更新和后续实际作答。至少包含足以检查四项的连续证据。多次作答整体支持与否由冻结的能力描述和观察窗口判断。

**四项检查**：A 变化知识能追溯到实际学习经历；B 变化范围与经历或合理迁移依据相符；C 提示下订正、自述理解和独立作答分别记录，能力判断与证据强度相称；D 状态变化得到后续多次独立表现支持。

**共同情境**：学生学习通分，完成一次提示下订正，之后正常作业中出现三道独立等价题。

- **高分示例｜5 分**：通分相关状态记录本课和练习来源；提示订正保留帮助条件；独立作答逐步支持计算能力提高，解释能力仍有待验证；无关的几何状态维持其原有依据。后续作答与这一细分状态相符。
- **低分示例｜1 分**：一次“我懂了”使所有学科变成完全掌握，找不到对应学习事件；提示订正记为独立成功；后续三道相关题仍暴露相同困难，状态却继续记为熟练。四项均未命中。

此项评模拟内部自洽。掌握数值满足预设公式只是结构证据，不能单独支持 D；后续证据不足时保留待观察状态。

### S6 学习变化的外部校准误差

**阶段**：学生行为与内部一致性完成迭代，并具备独立真实学生参照数据之后。

**测什么／怎么测**：在可比较的学段、起点、任务和模拟时间条件下，将模拟学生的独立作答曲线与真实学生参照曲线比较。学习进程、延迟保持、休息前后恢复按各自条件分别报告。将人物或班级分为拟合与保留验证样本。

**量化**：按预先固定的时间—任务单元计算成功率绝对误差的均值 MAE，范围 0—1，越低越好；同时保留各条件曲线和区间。参照数据缺失的条件保持待校准。

**共同情境**：保留样本中三个延迟测试点的真实正确率为 `[0.80, 0.70, 0.60]`，权重相等。

- **较好示例**：模拟为 `[0.78, 0.72, 0.59]`，MAE = `(0.02+0.02+0.01)/3 ≈ 0.017`，变化形态也接近参照。
- **较差示例**：模拟为 `[0.98, 0.98, 0.98]`，MAE = `(0.18+0.28+0.38)/3 = 0.28`，显著高估保持。

## 5. APP 端：教学交互质量

采用青河当前接入的 LearnLM 七项，指标 ID、四项检查和换算方式以来源实现为准。条件指标使用实际已触发的情境。下面的对话均为评分示例。

### mq_D1 认知提问率

**测什么／怎么测**：Judge 逐轮标注 APP 发言。事实回忆、因果推理、假设探索、反思元认知计入认知提问；状态确认 CHECKIN、无实质任务 JUNK 和纯陈述 NOT_QUESTION 不计入。

**量化**：认知提问轮数／APP 总轮数。先在会话内计算，再按会话等权汇总。

**共同情境**：学生学习异分母加法，APP 在五轮交互中引导学生理解。

- **较高示例｜80%**：五轮分别提出“为什么先统一每份大小？”“1/2 相当于几个 1/6？”“换成 1/4 呢？”“原先分母相加的问题在哪？”以及一句陈述总结。四轮有认知任务。
- **较低示例｜0%**：五轮只出现“懂了吗？”“清楚了吗？”“好不好？”“继续吗？”和纯陈述总结。

该比率描述提问行为；其数值与任务适配性、内容正确性和学习效果分别解释。

### mq_D2 策略切换

**测什么／怎么测**：选择学生连续两轮以上卡在同一处的完整对话，观察 APP 随后的教学动作。

**四项检查**：A 明确改变做法；B 新路径类型与原路径实质不同；C 新路径直接对应具体卡点；D 切换后仍有学生需要独立完成的步骤。

**共同情境**：APP 已用符号解释通分，学生连续两轮说不明白分母为什么不能直接相加。

- **高分示例｜5 分**：APP 转向等长纸条的等分活动：“先把半条分成六等份中的小格，数数占几格。”学生回应后，APP 让学生自己将三分之一改写成六分之几，再判断能否相加。切换为具体表征，针对单位大小，保留了学生任务。
- **低分示例｜1 分**：APP 再次完整复述同一套公式并给出答案，学生没有得到新路径，也没有留下需要自己完成的步骤。

### mq_D3 答对后深化追问

**测什么／怎么测**：选择学生已经答对的节点，观察 APP 是否推进原理理解与迁移。

**四项检查**：A 发起新追问或变式；B 指向核心原理或关键易混点；C 改变场景、条件或表征，要求迁移；D 将回答责任交给学生。

**共同情境**：学生正确算出 `1/2 + 1/3 = 5/6`。

- **高分示例｜5 分**：APP 问：“现在两条绳子原长不同，各取一半和三分之一，能直接说合起来是某条绳子的六分之五吗？请说明还需要知道什么。”随后等待学生回答。四项均命中。
- **低分示例｜1 分**：APP 只说“正确，本题结束”，没有新任务。

### mq_D4 信息量与分块控制

**测什么／怎么测**：选择多步骤任务，窗口包含学生实际理解或困惑信号。

**四项检查**：A 每条消息聚焦一个核心点，同条消息不同时引入三个及以上新概念；B 多步内容有序拆解且有衔接；C 关键步骤后交还话语权；D 至少一次根据学生反应改变粒度或速度。

**共同情境**：学生需要经历找公分母、等值改写、相加三个步骤，中途表示分子变化看不懂。

- **高分示例｜5 分**：APP 先让学生找公分母并等待；再问如何改写 1/2；学生卡住后，把这一步拆成“分母乘几”“分子应乘几”，得到回答后才继续相加。每条只推进一个核心点。
- **低分示例｜1 分**：APP 在一条长消息里混讲最小公倍数、约分、比与比例及完整答案，没有有序步骤；学生说卡住后，APP 原样重发长文并结束。四项均未命中。

### sq_D1 错误诊断与引导

**测什么／怎么测**：提供学生明确暴露的误区及认知来源，检查 APP 的诊断与引导。

**四项检查**：A 明确指出错误步骤或概念；B 说出错误名称或本质；C 解释认知来源或旧经验迁移；D 用反例、追问或对照推动学生自己修正判断。

**共同情境**：学生写 `1/2 + 1/3 = 2/5`，并说“整数相加就是两边分别加，所以我这样做”。

- **高分示例｜5 分**：APP 说：“你把分母也相加了，是把整数相加的办法搬到了分数符号的上下两部分。我们先验一下：半个蛋糕再加一块，怎么会比半个还少？2/5 和 1/2 谁大？”学生据此发现原规则不成立。
- **低分示例｜1 分**：APP 只说“再想想，正确答案是 5/6，记住就行”，没有诊断位置、本质、来源或自我修正活动。

### sq_D2 纠正与部分正确处理

**测什么／怎么测**：选择部分正确的原答，观察从指出局部表现到学生订正完成的整个窗口。

**四项检查**：A 指出正确部分及理由；B 用针对上一轮具体内容的反问推动发现错误；C 全程保留学生应得出的关键结论；D 学生纠正后确认修正点。

**共同情境**：学生把 `1/2 + 1/3` 改写成 `3/6 + 2/6`，随后写成 `5/12`。

- **高分示例｜5 分**：APP 说：“你把两项都化成六分之一为单位，这一步正确，因为两项现在每份一样大。3 个这样的份加 2 个，每份大小会改变吗？”学生答“不会，所以是 5/6”；APP 确认“对，合并的是份数，单位仍是六分之一”。
- **低分示例｜1 分**：APP 说“全错了，答案是 5/6”，随后结束；正确步骤没有得到说明，关键结论被直接给出，学生也没有完成自己的订正。

### sq_D3 正确答案确认

**测什么／怎么测**：选择学生正确回答，检查确认力度、归因和后续接续。

**四项检查**：A 明确确认正确回答；B 确认力度与回答重要性相称；C 指出正确依据或方法；D 以这个回答为支点继续相关追问。

**共同情境**：学生第一次解释清楚“同分母相加时单位不变，只合并份数”。

- **高分示例｜5 分**：APP 说：“对，你抓住了同一种单位才能直接合并份数这一点。那换成 1/2 和 1/3，首先要解决什么？”既确认概念突破，也用它接续下一步。
- **低分示例｜1 分**：APP 说“你还是完全没理解，现在背乘法口诀”，错误否定学生并转向无关任务，四项均未命中。

## 6. APP 端：知识关联与困难诊断

### D1 知识定位准确性

**测什么／怎么测**：对照专家审核的主考点与必要前置标签；包含复合知识题、同义表述和近似干扰节点。节点身份与可接受等价标签在运行前冻结。主考点与前置分别计算，已知标签不完整的案例进入复核。

**量化**：准确率 precision = 正确返回标签数／返回标签数；召回率 recall = 正确返回标签数／标准标签数。两者共同解释；标准非空而返回为空时，两者记 0。空标准案例单列多余标签率。

**共同情境**：某案例审核后的必要前置集合恰为 `{分数单位、等值分数}`。

- **较好示例**：APP 返回这两个标签，precision = 100%，recall = 100%。
- **较差示例**：APP 返回 `{分数单位、面积、角度、概率}`，precision = 25%，recall = 50%。

### D2 候选错因的区分与验证

**测什么／怎么测**：使用“同一错答、不同成因”的审核案例。评测器维护候选原因及能区分原因的回答分支；APP 依据实际问题获得相应回答。新诊断题先复核其可判定性。

**四项检查**：A 候选解释由现有证据支持；B 诊断任务能够区分候选；C 根据回答排除或保留原因；D 最终判断符合证据，歧义仍存在时保留不确定性。

**共同情境**：学生写 `1/2 + 1/3 = 2/5`；原因可能是套错规则，也可能是单位概念薄弱。隐藏病例事实是套错规则，学生实际上能解释分数单位。

- **高分示例｜5 分**：APP 保留两种原因，先请学生解释两个分母代表的单位；学生解释正确后，APP 降低单位概念薄弱的判断，再用 `1/2 + 1/2` 检查错误运算规则；回答支持后，将困难定位为规则误用并保留证据。
- **低分示例｜1 分**：APP 直接断定“你不会乘法”，只问“懂了吗”，无视学生正确的单位解释，最后仍记录“乘法完全未掌握”。四项均未命中。

### D3 诊断效率

**测什么／怎么测**：同一批有审核原因的案例给各 APP 相同诊断机会。例如每例最多三次诊断动作，记录每次获得的证据。一次动作定义为一个可独立回应的诊断任务；将多个任务塞入一句仍分别计数。

**量化**：固定机会内、经证据支持的诊断正确率。辅助报告成功病例平均动作数、失败数与未确定数。正确率分母包含全部可判病例，不能只保留成功案例。

**共同情境**：20 个病例，每例最多三次诊断动作。

- **较好示例**：18 例在限制内正确且有证据，正确率 90%；这 18 例平均两次动作，2 例仍未确定。
- **较差示例**：6 例正确，正确率 30%；虽然成功例平均只用一次动作，其余 14 例误诊或未确定，不能据此声称更高效。

## 7. APP 端：Memory

Memory 评分读取实际保存内容、证据引用、检索结果和教学动作。完整事件既可形成专项输入，也可从正常运行中截取。压缩容量、检索容量和观察窗口在案例中冻结。

### M1 有价值信息的选择与保真

**测什么／怎么测**：在有限记忆容量内处理关键错因、闲聊、提示订正和未完成任务；之后给出需要这些信息的续学任务。

**四项检查**：A 保留后续任务必需的信息；B 保存原答与帮助条件；C 区分观察事实与推测；D 压缩后仍能定位原始依据。

**共同情境**：学生聊了兴趣，又写出分母相加的原答，在 APP 帮助下订正，单位概念尚待验证；记忆最多容纳 200 字。

- **高分示例｜5 分**：记忆为“E12 原答 2/5；E15 在等分提示后订正为 5/6；疑似规则误用，单位理解待验证；下次先做独立变式。原答与提示见 E12/E15。”实际保存了关键内容、条件与来源。
- **低分示例｜1 分**：仅保存“喜欢蓝色，学习优秀，已经熟练掌握分数”，没有原答、帮助条件、来源或未完成验证。

### M2 跨事件整合与去重

**测什么／怎么测**：同一次作答以原消息、批改和摘要重复出现，然后加入一道真正独立的新题。

**四项检查**：A 识别重复来源；B 保留原答—提示—订正关系；C 独立作答保留独立身份；D 总结准确表达证据次数与条件。

**共同情境**：E1 是原错答；E2 是提示后的订正；E3 批改和 E4 摘要均引用 E2；E5 是第二天的新题独立作答。

- **高分示例｜5 分**：Memory 将 E3/E4 归回 E2，保留 E1→E2 的帮助链，E5 单独记一次独立成功；汇总为“一次提示订正、一次新题独立成功”。
- **低分示例｜1 分**：Memory 将 E2/E3/E4 算成三次独立成功，把 E5 与它们合并为一条无来源总结，丢失原错答与帮助条件。

### M3 冲突处理与错误修复

**测什么／怎么测**：先建立一条错误记录及派生摘要、方法记忆，再提供独立复核或学生澄清。随后查询受影响的记忆并继续教学。

**四项检查**：A 识别新旧证据冲突；B 按来源、时间和帮助条件裁决；C 更新受影响的派生记忆；D 后续调用采用更新结论。

**共同情境**：原记录把学生正确的等值改写误判成“不会通分”，摘要与练习计划据此生成；独立复核确认其通分步骤正确，错误在后续相加。

- **高分示例｜5 分**：Memory 标记原判定被复核替代，引用原步骤和复核证据，将困难改为相加时单位处理；同步更新摘要及练习计划，下次针对相加步骤教学。
- **低分示例｜1 分**：系统只追加一句“收到复核”，原错因、摘要与计划仍在使用，下次继续教已经会的通分步骤。

### M4 时间与适用范围管理

**测什么／怎么测**：混合已解决误区、最近困难和较久未验证的能力；在时间推进后查询当前记录与下一步任务。

**四项检查**：A 区分历史经历和当前判断；B 保留最近验证时间；C 限定困难与方法的适用情境；D 证据变旧或出现新矛盾时安排复核。

**共同情境**：两周前学生用纸条理解分数加法，当日独立成功；最近学习分数乘法，尚未验证旧知识保持。

- **高分示例｜5 分**：Memory 记“第 1 天纸条法帮助理解加法单位，当天独立验证成功；第 15 天保持待复测，乘法效果待观察”，下一次安排短保持题。
- **低分示例｜1 分**：保存“永远擅长分数，任何分数题都用纸条法”，没有时间、范围或复核任务，近期矛盾也不更新。

### M5 面向当前任务的检索

**测什么／怎么测**：设置词面相似干扰、跨表述的相关经历和缺失证据，固定返回容量，读取实际检索结果。

**四项检查**：A 取回当前任务所需证据；B 覆盖关键困难与前次进展；C 过滤会误导判断的相似记录；D 证据不足时实际继续检索或明确保留未知。

**共同情境**：学生问两种刻度单位为何不能直接相加；历史存在分数单位卡点、已完成的等分活动以及一条词面相似的无关文字题，长期保持记录缺失。

- **高分示例｜5 分**：检索取回单位不一致的困难与等分活动进展，过滤无关文字题；继续查找保持证据后明确“尚无保持验证”，据此准备诊断。
- **低分示例｜1 分**：只返回词面相似文字题，遗漏真实卡点和进展，并宣称“历史证明已经掌握”，没有继续查询或保留未知。

### M6 教学方法经验的形成

**测什么／怎么测**：同一学生经历多种讲法，结果包括自述理解、提示下成功、独立成功和后来失败。检查形成的方法记忆及后续更新。

**四项检查**：A 记录方法与任务条件；B 区分不同强度的效果证据；C 将方法效果限定为有依据的假设；D 根据新表现修正方法经验。

**共同情境**：纸条讲法之后学生说“懂了”，提示下答对；独立解释题仍失败，另一段分步追问后独立解释成功。

- **高分示例｜5 分**：记忆分别保存“纸条法：本次单位直观认识，自述及受助成功，独立解释未通过”“分步追问：本题独立解释成功，跨题效果待验证”；下一次优先验证分步追问的可迁移性。
- **低分示例｜1 分**：第一次自述理解后就写成“视觉型学生，所有学科都用图最有效”；忽略独立失败及后续成功来源，持续沿用这一结论。

### M7 跨会话任务接续

**测什么／怎么测**：在关键步骤中断，插入另一学科活动，隔天让学生用不同表述继续。观察检索、下一步行动及任务完成后的记忆。

**四项检查**：A 找回未完成目标；B 恢复已完成步骤和帮助程度；C 下一步针对未完成部分；D 完成后更新任务状态与验证证据。

**共同情境**：昨天学生在提示下完成通分，但还没独立解释分母为何保持不变；今天说“昨天最后那一步我想再试试”。

- **高分示例｜5 分**：APP 找回未完成的单位解释任务，注明此前通分得到提示；让学生自己解释并做一道变式，成功后关闭待办并关联新证据。
- **低分示例｜1 分**：APP 找错到语文背诵，声称学生昨天已独立完成分数题，继续无关教学，并把真正未完成的任务标为结束。

### M8 检索证据覆盖率

**测什么／怎么测**：专家为当前任务标注必需证据和可接受替代证据，固定检索容量；同一事实的多个等价记录只算一个证据单位。相关但非必需的证据另作相关性标注。

**量化**：必需证据召回率 = 取回必需证据数／必需证据数；返回证据准确率 = 有效相关证据数／返回证据数。标准非空而未返回证据时，两者记 0。

**共同情境**：任务需要“旧卡点、帮助条件、未完成步骤”三个证据单位，最多返回四个。

- **较好示例**：返回全部三个必需单位和一个有效近期验证，召回率 100%，准确率 100%。
- **较差示例**：返回四个单位，只有旧卡点相关，召回率 1/3，准确率 1/4。

### M9 Memory 对教学决策的贡献

**测什么／怎么测**：在同一冻结决策节点，分别提供完整 Memory、缺少目标记忆的 Memory、仅当前会话。固定模型、当前输入和决策机会；专家预先定义可接受行动集合及理由。适当行动必须实际执行，且理由与可见证据相符。

**量化**：各条件的适当决策率，以及完整 Memory 相对其他条件的配对百分点差。该测试在 APP 决策层完成，不依赖模拟学生随后一定受益。

**共同情境**：20 个任务都需要知道“学生已经会通分，但单位解释待验证”。

- **较好示例**：完整 Memory 下 18/20 次选择相应验证；缺少目标记忆时 10/20 次，增量为 +40 个百分点。
- **较差示例**：完整 Memory 下 8/20 次，缺少目标记忆时 10/20 次，增量为 −10 个百分点；更多记忆实际干扰了决策。

### M-E1 编造学习经历

**测什么／怎么测**：将记忆中的事实主张逐条追溯到完整、可访问的原始证据。确有证据的推断另标假设；原始档案缺失时记 awaiting_evidence。

**共同情境**：学生只有一次提示下订正。

- **高质量示例｜0**：“本次在提示下订正，独立掌握待验证”，来源可定位。
- **低质量示例｜1**：“该生连续三天独立全对”，完整档案中没有这些经历。

汇总为发生编造的有效记忆快照数／有效快照总数，另附具体事实主张。

### M-E2 使用其他学生经历

**测什么／怎么测**：在测试库中放入同名、同题或相似经历的不同学生记录，检查最终个人记忆与实际教学引用的归属。

**共同情境**：甲、乙做了同一道题，甲失败，乙成功。

- **高质量示例｜0**：甲的记忆只引用甲的作答，个人教学依据与学生身份匹配。
- **低质量示例｜1**：APP 对甲说“你刚刚已经独立做对”，引用的事件实际属于乙。

汇总为发生错用的有效个人会话数／有效个人会话总数。

### M-E3 派生记录被当作新增独立证据

**测什么／怎么测**：为同一原始作答生成多条合法引用记录，检查证据计数和实际更新依据。

**共同情境**：原答、批改、日摘要都描述同一次独立成功。

- **高质量示例｜0**：保留三个可追溯记录，但有效独立作答次数仍为 1。
- **低质量示例｜1**：有效独立作答次数变为 3，并据此提高能力判断的置信程度。

汇总为发生该错误的有效重复证据案例数／有效重复证据案例总数。

## 8. APP 端：学情画像

画像描述知识范围、任务条件、能力判断、置信程度、证据来源、最近验证时间和待验证问题。专项测试向 APP 提供审核后的证据，整链测试读取实际 Memory；两者分别报告。测试用的结构化字段可由评测适配器读取，对学生呈现继续使用自然教学表达。

### P1 能力表述的粒度与条件

**测什么／怎么测**：同一知识点给出“基础计算会、概念解释弱、提示后能订正”的混合表现，检查画像如何概括。

**四项检查**：A 区分接触经历与能力掌握；B 区分独立与受助表现；C 区分任务类型、难度或表征条件；D 整体判断保留局部强项与短板。

**共同情境**：学生上过通分课，三道基础计算独立答对；解释等值依据时需要提示；一道情境题失败。

- **高分示例｜5 分**：画像写“已接触通分；基础计算有三次独立成功；等值依据仅有受助解释；情境应用仍有困难”，各判断分别关联证据，整体标注能力范围而非单一全会标签。
- **低分示例｜1 分**：画像只写“上过课，所有分数任务已完全掌握”，将受助、计算、解释和情境任务全部等同。

### P2 证据权重与依赖处理

**测什么／怎么测**：使用表面正确率相同但证据构成不同的配对记录，覆盖重复作答、独立新题、理解自述和孤立失误。检查估计变化与证据贡献。

**四项检查**：A 区分独立成功与受助成功的贡献；B 重复来源不增加独立样本量；C 单次偶然结果不覆盖充分历史依据；D 判断强度与证据质量和数量相称。

**共同情境**：甲有三道新题独立正确和一次笔误；乙有同一道题受助订正的三个引用及一句“懂了”。

- **高分示例｜5 分**：甲的独立计算能力获得较强支持，笔误单列；乙只有一次受助成功，置信程度较低并等待独立验证；两组证据贡献和计数可追溯。
- **低分示例｜1 分**：乙的三个引用算三次独立成功且理解自述权重最高，判为比甲更熟练；甲一次笔误使全部历史证据被清零。四项均未命中。

### P3 稀疏证据与先修推断

**测什么／怎么测**：只给部分知识的表现；测试图中包含审核的必要前置、支持性关系和待复核映射，并设置目标表现与前置证据的冲突。

**四项检查**：A 标明直接观察与关系推断；B 区分关系类型及可靠性的推断力度；C 无证据节点保留未知；D 目标与前置矛盾时提出可验证解释。

**共同情境**：学生做对一题通分，却在近期等值分数解释题中失败；几何节点没有观察证据；图谱中另有一条支持性关系。

- **高分示例｜5 分**：画像保留“通分本题成功”的直接事实；把等值理解作为存在冲突的先修假设，考虑套程序、题目偶然性或映射粒度差异，安排独立解释题；支持关系只提供诊断线索，几何仍未知。
- **低分示例｜1 分**：一次目标题正确就把全部前置与支持节点标为完全掌握，覆盖已有失败证据，同时把几何未知写成零能力；没有任何验证任务。

### P4 随学习变化的更新

**测什么／怎么测**：按时间提供旧错误、受助订正、独立成功、延迟失败和评分复核，保存每个时点画像。

**四项检查**：A 当前判断与历史事实分开；B 新的独立能力证据推动对应更新；C 对单次波动保留不确定性；D 原证据被撤销或重评后重新计算受影响结论。

**共同情境**：第 1 天有误区，第 3 天多次独立成功，第 7 天一次失败；之后确认第 1 天另一条批改记录有误。

- **高分示例｜5 分**：历史误区仍有记录，当前计算能力因第 3 天证据提高；第 7 天失败引出保持疑问和复测，未直接推翻全部能力；复核撤销的贡献从当前估计及说明中同步调整。
- **低分示例｜1 分**：始终沿用第 1 天的笼统标签，独立成功无效；第 7 天一次失败又把全部能力归零；复核后仍保留原错误贡献，历史与当前无法区分。

### P5 跨知识与任务的泛化边界

**测什么／怎么测**：同一学生在局部任务成功，随后出现不同表征与复合题错误，再提供能定位错误的分步证据。

**四项检查**：A 能力扩展有对应证据；B 复合题错误定位到证据支持的范围；C 局部短板保留局部范围；D 反例出现后收缩或修正推断。

**共同情境**：学生数值通分正确，分数应用题中单位理解正确但列式错误；另有已独立通过的几何任务。

- **高分示例｜5 分**：画像支持数值通分能力，将本次困难限定在题意到算式的转换；收缩此前“应用熟练”的推断，保留几何能力及已有单位理解证据。
- **低分示例｜1 分**：先从一道计算题宣布全部应用熟练；应用题出错后又把分数、几何和整科能力全部判为薄弱，无视定位证据及反例。

### P6 学习偏好与方法适配判断

**测什么／怎么测**：使用学生自述偏好与实际独立表现不完全一致的多情境记录。比较教学经验时提供起点、难度和帮助条件。

**四项检查**：A 分开记录自述偏好与实际收益；B 适配结论绑定任务和时期；C 比较考虑起点、难度与帮助条件；D 证据不足时保留假设并实际提出验证任务。

**共同情境**：学生说喜欢故事讲法，故事后觉得有趣但独立解释仍失败；在相同起点和难度的另一个任务中，分步提问后成功。

- **高分示例｜5 分**：画像记“喜欢故事呈现；当前单位解释任务中，分步提问有更强独立表现证据；样本有限”，限定条件并安排新题验证。偏好和方法适配各有证据。
- **低分示例｜1 分**：仅据自述永久标记“故事型学习者，所有学科必须故事化”，忽略难度和帮助差异，也不验证独立结果。

### P7 主动补齐画像

**测什么／怎么测**：在有限诊断机会下，让 APP 选择最需要补齐的信息并提出任务；根据实际获得的回答检查更新与后续教学。

**四项检查**：A 选中影响下一步教学的关键未知；B 任务能区分候选能力状态；C 任务适合学生且产生独立证据；D 据结果更新画像与下一步安排。

**共同情境**：学生会照步骤通分，但不清楚是真懂等值关系还是记忆程序；只有一次诊断机会。

- **高分示例｜5 分**：APP 给出未做过的等值判断并要求说明理由，允许学生独立完成；依据解释确认或保留概念理解疑问，再选择应用练习或单位解释。
- **低分示例｜1 分**：APP 问“今天开心吗”，代学生回答后把概念状态改为完全掌握，继续预设流程。没有获得区分能力状态的证据。

### P8 未来独立作答预测误差

**测什么／怎么测**：在时间点 t 冻结画像，预测下一道保留题在规定难度和独立条件下的答对概率 p，再由独立评分器给出 y。用于预测的数据仅截至 t。

**量化**：Brier 分数 = `mean((p-y)^2)`，y 为 0/1，范围 0—1，越低越好。具有部分分的题先按审核规则确定本指标的二元成功事件；原部分分另行保存。掌握指数需先通过明确映射转为成功概率。

**共同情境**：同一批四道题，实际独立结果为 `[1,1,0,0]`。

- **较好示例**：预测 `[0.8,0.7,0.3,0.2]`，Brier = `(0.04+0.09+0.09+0.04)/4 = 0.065`。
- **较差示例**：预测 `[0.2,0.3,0.9,0.8]`，Brier = `(0.64+0.49+0.81+0.64)/4 = 0.645`。

四题只演示计算。正式结论需要足够样本、学生分组和区间。

### P9 概率校准

**测什么／怎么测**：在足量保留题上比较预测概率与实际成功频率，分箱规则在评分前固定，同时展示可靠性曲线。不同难度、学科和帮助条件分层观察。

**量化**：ECE = `Σ (n_b/N) × |该箱平均预测概率 − 该箱实际正确率|`，越低越好。报告每箱样本量；与 P8 共同解释模型的区分能力。

**共同情境**：100 道题被预测为约 80% 能独立答对，且全部落入同一预定概率箱。

- **较好示例**：实际答对 79 道，本例校准误差为 0.01。
- **较差示例**：实际答对 35 道，本例校准误差为 0.45，APP 明显过度自信。

### P10 未知处理能力

**测什么／怎么测**：在同一固定题组中允许 APP 选择哪些任务有足够证据给出确定预测。置信排序或弃判规则在保留集之前冻结。所有题的实际结果均采集，便于计算覆盖—误差曲线。

**量化**：覆盖率 = 给出预测的题数／全部可预测题数；对已预测子集计算 Brier。比较相同覆盖率下的误差，并完整保留曲线。全部弃判时覆盖率为 0、误差未定义。

**共同情境**：100 道题，比较双方覆盖率均为 60% 的结果。

- **较好示例**：对证据充分的 60 题作答，Brier = 0.08；其余 40 题明确保留未知并提出补证据方向。
- **较差示例**：同样预测 60 题，但高置信选中大量缺乏依据的任务，Brier = 0.30；或只预测 5 题却用低误差宣称整体更准确，这种报告无法支持同覆盖率比较。

### P11 变化跟踪能力

**测什么／怎么测**：用独立测验建立能力变化和稳定窗口，随后按顺序释放 APP 可见的新证据；画像更新不能提前读取参照测验标签。变化判据、观察上限和确认规则在测试前固定。

**量化**：确认变化所需的新证据数；在观察上限内的检出率；稳定窗口误报警率。未检出案例记为超过观察上限，同时计入检出率分母。

**共同情境**：10 个已独立确认变化的窗口，每个最多释放 5 条新证据；另有 10 个能力稳定窗口。

- **较好示例**：9/10 个变化窗口被检出，成功窗口中位需要 2 条证据；稳定窗口 1/10 误报警；另 1 个变化窗口明确记为超过 5 条仍未检出。
- **较差示例**：仅 3/10 检出，成功窗口中位需要 5 条；稳定窗口 7/10 误报警，其余变化窗口保留为未检出。

## 9. APP 端：持续教学效果

当前可以保存独立作答、迁移与保持结果。解释 APP 因果收益和开展 L4 时，需要相应学生模型验证及可比实验条件。模拟隐状态的增长与独立测试成绩分别报告。

所有测试固定题目与评分标准；学生独立作答，教学帮助暂停，画像和 Memory 在对应预测时间点冻结。题目按等价题族分配到教学、即时测试、迁移和延迟测试，避免把训练原题的复述当作迁移。正式分数按学生—种子或独立学生区组汇总，避免将同一学生多道题视为多个独立受试者。

### L1 独立学习增益

**测什么／怎么测**：教学前后使用审核过的难度匹配题组；AB/BA 顺序在区组间平衡。计算个人前后变化，同时报告完成率。前后差表示表现变化，额外练习或时间因素需在对照实验中处理。

**量化**：后测得分率 − 前测得分率，单位为百分点。

**共同情境**：两种示例轨迹的前测均为 40%，满分与题组难度已匹配。

- **较好示例**：后测 75%，增益 +35 个百分点。
- **较差示例**：后测 35%，增益 −5 个百分点；对话中的多次“我懂了”不改变该结果。

### L2 迁移收益

**测什么／怎么测**：使用新条件、新情境或新表征的独立任务，分别覆盖近迁移和较远迁移。任务目标与难度经审核。在具备实验条件时比较匹配区组的 APP 与参照条件。

**量化**：分层迁移得分率；配对条件差 = APP 条件 − 参照条件，单位为百分点。两种结果同时保留。

**共同情境**：相同起始能力区组的参照条件在迁移测试中平均得分 45%。

- **较好示例**：APP 条件平均 70%，配对平均增量 +25 个百分点。
- **较差示例**：APP 条件平均 40%，增量 −5 个百分点；原题订正率即使很高，也不能替代迁移结果。

### L3 延迟保持收益

**测什么／怎么测**：在固定模拟时间间隔后给出独立等价测试。控制或记录期间再次接触目标知识的经历。参照组采用相同复测日程；使用平行题组控制重复测试练习效应。

**量化**：延迟得分率、相对即时测试的变化，以及具备对照时的配对延迟差。分别保留即时水平，避免只用下降幅度判断保持优劣。

**共同情境**：即时测试均为 80%，第 7 天等价测试，期间目标知识接触条件匹配。

- **较好示例**：第 7 天为 75%，变化 −5 个百分点。
- **较差示例**：第 7 天为 30%，变化 −50 个百分点。

### L4 Memory 与画像的增量贡献

**阶段**：学生模拟完成必要验证，且配对分支与实验输入隔离能够执行后。

**测什么／怎么测**：开展两组独立比较。Memory 比较完整教育 Memory、仅当前会话、相同容量通用摘要；画像比较相同 Memory 下使用画像、暂不提供画像，以及提供独立诊断参照画像的实验条件。一次比较只改变目标因素，固定模型、起点、材料、学习机会和停止规则；教学内容可按各自策略生成。

**量化**：迁移与延迟保持的配对平均差及置信区间。按实验条件分别报告实际请求、token 与耗时；它们是成本观察量，不构成学习成绩。参照画像只对对应实验分支可见。

**共同情境**：多个匹配学生—种子区组比较完整教育 Memory 与仅当前会话。以下为构造的汇总结果。

- **较好示例**：迁移增量 +12 个百分点，95% 区间 `[+6,+18]`；保持增量 +9，区间 `[+3,+15]`。结果支持这些测试条件下的正向增量。
- **较差示例**：迁移增量 −8，区间 `[−13,−3]`；保持增量 −5，区间 `[−9,−1]`。结果显示引入 Memory 后表现变差。

若区间跨越 0，报告估计值与不确定性，不能据此直接认定有效或无效。画像比较使用同样的读数方式，参照画像的结果用于估计画像准确性改善的潜在空间。

## 10. 一组连续病例如何连接各指标

下表是共同的构造病例。实际测试时只向被评 APP 释放当时能够获得的证据；评测器按时间点冻结输入。

| 时间／事件 | 发生的事 | Memory 理想记录 | 画像理想判断 |
| --- | --- | --- | --- |
| 第 1 天 E01 | 学生写 `1/2+1/3=2/5`，并说明自己的规则 | 保存原答、原话与任务身份 | 存在错误证据；规则误用与单位概念需要区分 |
| 第 1 天 E02 | APP 提示后订正为 `5/6` | 保存帮助条件与 E01→E02 关系 | 本次受助订正成功，独立能力待验证 |
| 第 1 天 E03／E04 | 批改和摘要引用 E02 | 将派生记录归到同次订正 | 独立证据量不因引用次数增加 |
| 第 3 天 E05／E06 | 两道新题独立成功，概念解释仍困难 | 独立成功各保留身份；解释困难另存 | 程序性计算有进步，概念解释仍需诊断 |
| 第 7 天 E07 | 延迟题失败 | 记录任务条件、时间和原错误 | 保持稳定性存在疑问，安排复测并保留已有进步 |

这个病例可以产生 M2 的去重检查、M4 的时效检查、P1 的能力分解、P2 的权重检查、P4 的动态更新，以及 P11 的跟踪任务。各自仍按独立冻结窗口判分，病例共享不意味着可以把同一次成功多次计入学习效果。

### 10.1 中间分如何形成

以 M2 为例：系统识别 E03/E04 引用 E02，保留 E01→E02 帮助链，但错误合并 E05/E06，最终写成“三次独立成功”。A=true、B=true、C=false、D=false，因此得分为 `1+2=3`。评分者需要同时提供正确的来源合并记录和错误的总结原文。

```json
{
  "case_id": "example-memory-dedup-001",
  "metric_id": "M2",
  "rubric_version": "qinghe-k12-eval/1.0",
  "status": "scored",
  "checks": {"A": true, "B": true, "C": false, "D": false},
  "score": 3,
  "evidence": {
    "A": [{"event_id": "E04", "field": "source_event_id", "value": "E02"}],
    "B": [{"event_id": "E02", "field": "preceding_attempt", "value": "E01"}],
    "C": [],
    "D": []
  },
  "counterevidence": {
    "C": "E05 与 E06 在保存记录中共用一个独立作答身份",
    "D": "总结原文：三次独立成功"
  },
  "reason": "派生引用已去重，帮助链保留；独立新题身份与最终独立成功数有误。"
}
```

该 JSON 展示新增指标结果结构。实际运行补充输入哈希、模型身份、Judge 原响应及引用定位。LearnLM 继续采用原协议中 true 项的原文证据与 false 项空证据要求。

## 11. 从设计到正式运行

### 11.1 案例准备与判分校准

1. 为每个指标制作同情境的高低表现对，并补充只有部分检查项命中的中间案例、边界案例和不适用案例。为 Memory／画像同时保存上游证据、状态前后版本与后续行动。
2. 学科标签、诊断原因和可接受教学行动由独立审核者确定。合理答案不唯一时保存可接受集合或等价规则；证据仍有争议的案例保留待裁决。
3. 两名评分者独立判 A—D 或 0/1，再与 Model Judge 比较；报告一致率、分歧类型和发生位置。先校准检查点含义，再讨论指标分布。
4. 冻结案例、量规、来源哈希、模型配置、观察窗口及统计方式后执行。量规变化形成新的版本，跨版本比较需重评共同样本。

### 11.2 测试对象与分母

| 类别 | 主要统计单位 | 必须一起报告 |
| --- | --- | --- |
| S1／S3／S5 | 学生—知识范围—连续窗口 | 学生数、题数、窗口数、后续证据覆盖 |
| S2 | 匹配学生或属性组 | 匹配条件、组数、每组有效情境 |
| LearnLM | 完整会话；mq_D1 先按轮标注 | 会话数、轮数、条件覆盖与中断状态 |
| D／M／P 行为项 | 冻结案例或状态更新窗口 | 计划、有效、未触发、待证据、错误数 |
| P8—P10 | 学生—保留题预测 | 预测数、学生数、难度／学科层次与覆盖 |
| P11 | 变化或稳定窗口 | 检出、未检出、观察上限与误报警 |
| S6／L | 学生或学生—种子区组 | 完成、未完成、失败、退出原因及区间 |

多次 Judge 重判先在病例内汇总；同一学生的多题和多时间点具有相关性。区间优先以学生或配对区组重采样。各指标分别报告，保持能力质量、错误率和学习收益的原始含义。

教学或作答失败需要保留任务状态。能够独立判定的空答按该任务预先冻结的评分规则处理；技术性缺失不能当作学生不会。学习效果实验预先规定退出与缺失处理，并同时展示完成率和共同完成样本的结果，避免只保留成功轨迹。

### 11.3 报告应支持的决策

| 观察到的结果 | 可以定位的问题 | 下一步证据 |
| --- | --- | --- |
| M1—M4 低，P 也低 | 上游证据保存、整合或更新有缺陷 | 对比正确证据输入下的画像专项表现 |
| M8 高，M7／M9 低 | 已取到证据，但没有据此接续或做出合适决策 | 检索结果到下一步行动的原始链条 |
| P1—P7 高，P8／P9 差 | 画像表达与推理步骤合理，但预测或数值校准不足 | 固定任务条件下的保留题预测与校准曲线 |
| LearnLM 高，L 结果不确定 | 已观察到教学行为，收益证据仍不足 | 学生模型验证与可比独立迁移、保持数据 |
| S5 高，S6 待校准 | 模拟内部自洽，教育真实性的外部依据待补齐 | 同学段独立参照数据与保留样本 |
