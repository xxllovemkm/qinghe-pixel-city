# K12 图谱与教育 Agent Memory

教育 Agent 通过 K12 知识路径组织每位学生的实际提问、上传作答、APP 批改与后续学习记录。知识地图、教学方法记录和练习计划共同服务于个性化教学。

## 学习记录路径

学生的问题、本人上传的作答与错题记录进入统一知识关联服务。`tag_question(question_text, item=None, entry=...)` 接收三个入口并复用 `tag_item`：已审核题目根据正文、内容哈希、来源与映射版本确认归类；任意新问题按图谱标题、目标和要点生成候选。候选保留命中文字、字段和原因，置信值表示规则分档。

确认关联的作答进入 `learning_table(student_id, day)`。每条学习范围记录不同题总数、错题数、正确率、当前星级及逐题历史。低置信关联保留明细。提问、求助与继续教学的发言进入对话记录，作答结果由独立批改服务判断。

默认统计近 14 天，每个目标至少 3 道不同题才形成星级：正确率达到 60% / 80% / 95% 对应一 / 二 / 三星，题量不足为 `stars=null`。参数通过 `configure_learning` 设置并随检查点保存。题目使用稳定等价身份跨入口去重，原答进入统计，提示后的订正保留历史；隔日独立复测可以更新该题当前结果，并据此调整星级。

`wrongbook(student_id)` 从本人 APP 已观察的错误作答聚合原始错误、后续尝试和关联依据。“用户学情”包含自然语言摘要与结构化学习范围；逐题记录可以回到实际事件。

## 图谱层次与教学记忆

3D 图的复合节点提供稳定归类和范围覆盖，其下的具体学习目标记录题量与星级。`contains` 表示包含，`prerequisite` 表示先修，`course_sequence` 表示课程顺序。每条关系保留来源与版本。

学生真实知识状态与 APP 推断分别保存。课堂讲授把实际涉及的知识点写入每名学生的学习经历；模拟器的个人状态驱动后续作答。学生回家完成并提交作业后，APP 根据本人题目、原答、批改及后续对话形成学习判断。教师负责课程推进、讲解、组织练习和布置作业。

| 记忆内容 | 用途 |
| --- | --- |
| 知识点学情 | 定位最近学习范围、题量、当前表现与证据 |
| `difficulty_hypotheses` | 记录实际卡点及推断依据 |
| `teaching_effects` | 记录采用的讲法和之后出现的实际回应 |
| `task_continuity` | 接续上次做到的步骤与尚未完成的任务 |
| `practice_plan` | 独立安排巩固、变式与保持练习 |

教学方法与后续表现的先后关系用于形成假设，因果效果需要独立实验。APP 将内部记忆用于选择讲法与下一步任务，对学生输出具体解题内容和作答反馈。

## 课程与题目来源

首个连续单元包含 70 道按 Smartedu《通分》教学目标编制的例题、随堂题和家庭作业。固定题目以正文、作答契约、来源和哈希核验其课程关联；`curriculum_authored_alignment` 的 0.9 是固定课程关联策略值。该值表示预设任务契约，通过独立语义标注才能评估关联准确率。任意新提问仍通过独立候选检索处理。

简答题按完整事实与关系命题判分，保存命中依据、冲突、缺项和未识别表达。规则尚不能判断的回答保留 `correct=None`，供后续语义评阅接续。扩充题库与规则后，按相同内容审核流程建立知识关联。
