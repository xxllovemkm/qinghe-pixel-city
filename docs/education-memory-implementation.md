## 学校日、空间与 APP

学生从本人住所出发，经过城市道路、校门和教学楼进入对应教室。全班按六节固定日课表参与课堂，各生依据已听讲授、本人状态和实际经历独立生成随堂作答，教师根据可见课堂表现反馈。

放学后学生沿道路返回本人住宅，按同一学生的因果顺序完成各份作业、整份提交、逐题批改与连续辅导。题目、原答、提交哈希、批改、对话和跨课时历史使用各自的稳定身份。模拟活动使用分钟，模型排队、网络传输与处理另计现实耗时。

APP 读取该生实际分享的题目、原答、对话、自己的 Memory 与公开课程目标候选。模拟器真实状态进入学生行为生成，研究观察页面可对比两种画像。APP 每条观察核对本人和同一道题的证据归属。

手机沿用 StudyMode 的内容布局与 Markdown／KaTeX 渲染，资源许可和来源清单见 `public/study-ui`。可查看完整作业、逐题原答和分步反馈、切换历史作业、围绕选定题目继续交流。对话明确当前作业、当前题与待回应 ID，逐轮保留 `response_to_id`。

## 人物与个人知识画像

`learner_profiles.py` 由学校日事件调用，状态保存为 `student.learner_profile`。它是可序列化的纯状态服务；人物初始化、真实状态、APP 预测和观察投影沿同一运行处理。

人物设定包含性别、年级、肤色、发色、服装和身高比例，以及学习速度、保持倾向、学习投入、起始准备、求助主动性、兴趣、学习方式和任务目标。默认值由固定种子与学生身份生成。初始已学目标须属于实际来源图谱，声明掌握度为 0–1；来源、数值和人物种子随运行保存。

| 视角 | 更新依据 | 掌握度定义 |
| --- | --- | --- |
| 真实画像 | 初始条件、课堂、练习、辅导、休息与模拟时间 | 模拟器隐状态；学习增加、疲劳抑制学习、休息恢复疲劳、时间间隔引起遗忘 |
| APP 预测画像 | 本人分享题目与原答、APP 评分、Memory 实际选中的来源目标、原事件依据 | 独立 Beta 先验与加权评分证据的后验均值 |

量规版本为 `qinghe-learner-dynamics/1`：

- 真实学习增量为 `(1 − mastery) × (1 − exp(−rate × 每节点学习分钟))`；`rate` 由学习速度、投入、疲劳和活动类型决定，同次活动的有效分钟分配到参与目标。
- 遗忘为 `mastery × exp(−0.04 × (1 − retention) × 间隔天数)`。疲劳每学习分钟增加 0.004，休息和活动间空闲按 `exp(−0.02 × 分钟)` 恢复。
- APP 初始为 `Beta(1,1)`；掌握预测为 `(1 + 加权得分比例之和) / (2 + 证据权重之和)`。独立作答权重 1，求助后或独立性未明确的作答权重 0.35；证据权重按时间衰减。
- 同一作答的重评替换原贡献；分享、对话和 Memory 关联记录接触，学生的理解自述与评分成功证据各自保存。
- 0–3 星阈值为 0%、60%、80%、95%。这些阈值是可审查的模拟量规，教育测量准确率与长期学习收益仍需独立校准。

两个个人 3D 图只显示各自已经学过的目标，每个显示节点都有有限的 0–1 掌握度、星级和来源。节点标签、列表与详情显示百分比，详情包含原教学目标和原始课堂／作答／对话证据。关系通过 `CurriculumGraph.profile_graph` 从实际来源结构中取得，并限制为本图已经显示的端点。两种视角的节点集合、数值和更新时间可以不同。

画像事件保存原参数、节点身份、原学习证据和输入哈希；重复事件幂等，同一身份内容冲突会拒绝。历史运行缺少连续真实状态时显示 `historical_state_unavailable`；从后续保存时刻开始记录的状态注明起点。初始条件、实际模拟隐状态与真实学生能力测量具有不同的证据含义。

## 学习效果实验设计

以相同学生初始状态、材料和随机种子构成配对区组，比较三种条件：完整教育 Memory、仅当前会话历史、相同容量的通用摘要 Memory。三组使用相同模型、工具、每题最大轮数和请求预算；比较教学方法时只改变目标方法选择策略，材料、模型与反馈时机保持一致。每次运行先固定条件、图谱哈希、题目和评测配置，再开始采集。

先做 6 名模拟学生 × 20 个预注册种子的机制实验，每个区组各执行三种条件，训练阶段为三天。用于训练的原题与用于测试的换数、换图、解释和迁移题分开；第 4 天和第 7 天设置独立保持测验。测试期间冻结 Memory 更新并暂停教学提示，评分器读取学生实际独立作答。评测器单独保存标准答案、标签和模拟参照，APP 只读取按条件提供的本人材料和历史。

主要指标为配对的独立迁移正确率与隔日保持率，分别按学生／种子区组计算差值及区间；同时报告题目覆盖、拒答、错误数和结束原因。节点推断质量按真实参照节点集合、直接证据与假设分别统计漏观测、错误关联及估计偏差。请求数、token 和现实耗时属于成本指标。Judge 仅评价预注册的教学行为，报告各指标自己的有效会话分母，不与学习成绩合并成总分。

2026-09-12 的三日运行用于对应版本的机制和流程检查。上述配对实验尚未执行；模拟器的学习函数同时影响条件差异，实验结果只能支持模拟机制内部的结论。关于真实学生的因果收益，还需独立学生数据、预注册随机分组与盲评保持／迁移任务。
